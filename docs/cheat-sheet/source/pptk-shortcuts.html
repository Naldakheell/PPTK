PPTK

PPTK Keyboard Shortcuts

Build slides faster in PowerPoint — insert, align, space and format without leaving the keyboard.

PPTK 1.1.0 — Windows
Where shortcuts workOn the slide in Normal view, with shapes or nothing selected. Keys go to PowerPoint as usual while you type in text, and in the ribbon, dialogs, notes, Slide Show and master views.
Single keysPress one letter. R inserts a rectangle.
SequencesPress A, release, then L within 1 second. Esc cancels.
Any keyboard layoutLetters follow key positions, so they also work on an Arabic keyboard. Needs the PPTKKeys helper running.
