Windows PPTK ribbon controls that exist on origin/mac-development
(src/PPTK DEV.pptm customUI/customUI.xml) and are not wired on Windows.

Reason: the callback is not a public procedure in the Windows VBA project
inside src/PPTK-WINDOWS-FINAL.pptm. Source modules for many of these
features are in the repository, but they are not imported into that project.
They are omitted instead of being pointed at a different command.

Visibility and enablement callbacks are also absent from the Windows project,
so the Windows ribbon does not call InstrumentaGetVisible, InstrumentaInitialize,
RibbonObjectGetImage, or the EnableWhen* callbacks. Built-in idMso controls
remain visible. Custom commands that need those callbacks are listed below.
